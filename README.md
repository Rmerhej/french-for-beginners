# French for Beginners 🇫🇷

Application web éducative pour apprendre le français depuis le niveau débutant absolu.

## Fonctionnalités
- Leçons interactives structurées
- Vocabulaire avec images et exemples
- Exercices et quizzes corrigés automatiquement
- Système d'authentification (utilisateurs + admin)
- Upload et optimisation d'images (Thumbnailator)
- Interface moderne avec **Bootstrap 5**

## Technologies
- **Backend** : Spring Boot 3.3.x + Java 17
- **Frontend** : Thymeleaf + Bootstrap 5 + CSS/JS
- **Base de données** : MySQL
- **ORM** : Spring Data JPA
- **Sécurité** : Spring Security
- **Build** : Maven
