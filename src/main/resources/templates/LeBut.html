📘 L'expression du but

Exprimer l'intention, l'objectif recherché et la finalité d'une action en français

🎯 Objectif

À la fin de cette leçon, vous saurez exprimer le but ou l'intention en utilisant les structures adaptées selon que le sujet de l'action est le même ou change, en choisissant entre l'infinitif et le subjonctif.

Qu'est-ce que l'expression du but ?

Le but répond à la question « Dans quel but ? » ou « Pour quoi faire ? ». Il indique l'objectif visé, l'intention qui pousse à réaliser une action.

  • Exemple d'intention : J'étudie le français pour travailler à Paris.
  • Exemple de finalité : Je parle doucement afin que le bébé ne se réveille pas.

1. Même sujet : Le but suivi de l'infinitif

Lorsque la personne qui fait l'action principale et celle qui réalise le but sont identiques, on utilise des prépositions suivies d'un verbe à l'infinitif.

  • Pour (+ infinitif) : Le plus courant, exprime un objectif simple. Ex: Je m'entraîne pour réussir l'examen.
  • Afin de / De manière à / De façon à (+ infinitif) : Plus formels ou soutenus. Ex: Il travaille dur afin d'obtenir une promotion.
  • De peur de / De crainte de (+ infinitif) : Pour exprimer un but négatif (éviter quelque chose). Ex: Elle parle bas de peur de déranger.

2. Sujets différents : Le but suivi du subjonctif

Lorsque le sujet de l'action principale est différent du sujet de l'action du but, on utilise une conjonction suivie obligatoirement du mode subjonctif.

Objectif positif

Pour que (+ subjonctif) Je t'explique la règle pour que tu comprennes.
Afin que (+ subjonctif) Plus formel.
Il laisse un message afin que nous soyons prévenus.

Objectif d'évitement (Négatif)

De peur que / De crainte que (+ subjonctif) Attention au "ne" explétif facultatif mais fréquent :
Je ferme la fenêtre de peur qu'il (ne) pleuve.

Tableau récapitulatif : Infinitif vs Subjonctif

La règle d'or pour choisir la bonne structure selon les sujets de la phrase.

Même sujet $\rightarrow$ Infinitif Sujets différents $\rightarrow$ Subjonctif
Je cours pour arriver à l'heure.
(Je cours / J'arrive)		 Je cours pour que tu arrives à l'heure.
(Je cours / Tu arrives)
Il économise afin d'acheter une voiture.
(Il économise / Il achète)		 Il économise afin que son fils achète une voiture.
(Il économise / Son fils achète)

⚠ Erreurs fréquentes

❌ Incorrect ✅ Correct
Je viens pour que tu m'aides. (Quand les sujets sont identiques, pas de "pour que"). Je viens pour t'aider. (Même sujet : pour + infinitif).
Je travaille pour que j'achète une maison. (Répétition lourde du même sujet). Je travaille pour acheter une maison. (Utiliser l'infinitif quand le sujet ne change pas).
Il fait attention pour que tu ne fais pas d'erreurs. (Oubli du subjonctif). Il fait attention pour que tu ne fasses pas d'erreurs. (Après pour que, le verbe est au subjonctif).

💬 Dialogue

Élodie : Pourquoi tu organises cette réunion de dernière minute ?

Thomas : Je l'organise afin de faire le point sur le projet avant la date limite.

Élodie : D'accord. Tu veux que je prépare un dossier pour que toute l'équipe ait les chiffres sous les yeux ?

Thomas : Oui, c'est une excellente idée, de manière à éviter les malentendus pendant la discussion.

Élodie : C'est parti, je m'en occupe tout de suite !

✅ À retenir

  • Même sujet : Utilisez pour, afin de, de peur de + infinitif.
  • Sujets différents : Utilisez pour que, afin que, de peur que + subjonctif.
  • Le but exprime l'intention recherchée ou l'objectif à atteindre.
  • Attention à ne pas utiliser pour que si les deux actions sont menées par la même personne.
