📘 Les auxiliaires : être et avoir

Cours de français pour adultes débutants

1. Qu’est-ce qu’un auxiliaire ?

Un auxiliaire est un verbe utilisé pour former les temps composés (passé composé, etc.).

  • avoir
  • être
2. L’auxiliaire “avoir”

Utilisation principale : la majorité des verbes

Exemples :

  • J’ai mangé une pomme 🍎
  • Tu as parlé français
  • Nous avons travaillé
3. L’auxiliaire “être”

Utilisation principale : verbes de mouvement et verbes pronominaux

Exemples :

  • Je suis allé(e) à l’école
  • Elle est venue hier
  • Nous sommes partis
⚠️ Avec “être”, le participe passé s’accorde :
Elle est allée / Ils sont partis
4. Conjugaison rapide
Avoir
  • j’ai
  • tu as
  • il a
  • nous avons
  • vous avez
  • ils ont
Être
  • je suis
  • tu es
  • il est
  • nous sommes
  • vous êtes
  • ils sont
🧠 À retenir : Avoir est utilisé dans la majorité des cas. Être est utilisé pour certains verbes et les verbes pronominaux.
