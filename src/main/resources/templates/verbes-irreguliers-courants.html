📘 Les verbes irréguliers courants

Les verbes qu'on utilise tous les jours : venir, pouvoir, vouloir, devoir, prendre, savoir, voir, dire.

1. Pourquoi « irréguliers » ?

Les verbes réguliers (comme parler) suivent un modèle. Les verbes irréguliers changent de forme : il faut les apprendre. Heureusement, ce sont des verbes très fréquents : vous les entendrez et les direz chaque jour.

💡 Astuce : pour presque tous ces verbes, « je » et « tu » ont la même forme (je peux, tu peux ; je veux, tu veux ; je dois, tu dois).

3. Exemples dans la vie de tous les jours

📌 Je viens de Paris.
→ I come from Paris.

📌 Je peux t'aider.
→ I can help you.

📌 Elle veut un café.
→ She wants a coffee.

📌 Nous devons partir.
→ We must leave.

📌 Je prends le bus.
→ I take the bus.

📌 Je ne sais pas.
→ I don't know.

📌 Je vois un oiseau.
→ I see a bird.

📌 Vous dites la vérité.
→ You are telling the truth.

4. Pouvoir, vouloir, devoir + verbe à l'infinitif

Ces trois verbes sont très souvent suivis d'un autre verbe, qui reste à l'infinitif :

📌 Je peux venir à 18 h.
→ I can come at 6 pm.

📌 Nous voulons apprendre le français.
→ We want to learn French.

📌 Vous devez arriver à l'heure.
→ You must arrive on time.

On dit : « Je voudrais un café » (plus poli que « je veux ») et « Pouvez-vous m'aider ? » pour demander gentiment.

5. Attention aux pièges

  • vous dites (et non « vous disez »), vous faites.
  • ils prennent, ils viennent : deux n au pluriel, et la forme est différente de « il prend », « il vient ».
  • savoir = connaître une information ou une compétence : Je sais nager. / pouvoir = être capable ou avoir la permission : Je peux entrer ?

Petit exercice

Complétez avec le bon verbe : venir, pouvoir, vouloir, devoir, prendre, savoir, voir, dire.

  1. Je ___ de Paris. (venir)
  2. Tu ___ parler plus fort ? (pouvoir)
  3. Nous ___ partir tôt. (devoir)
  4. Elles ___ le train. (prendre)
  5. Vous ne ___ pas la réponse. (savoir)
Voir les réponses
  • je viens
  • tu peux
  • nous devons
  • elles prennent
  • vous ne savez pas

Résumé

  • Les huit verbes se retiennent par la pratique : relisez le tableau chaque jour
  • pouvoir / vouloir / devoir + infinitif
  • je et tu ont souvent la même forme
  • Attention : vous dites, ils prennent, ils viennent
