📘 Les adjectifs démonstratifs

Montrer et désigner une personne ou une chose

🎯 Objectif

À la fin de cette leçon, vous serez capable d'utiliser ce, cet, cette, ces pour montrer quelque chose.

Qu'est-ce qu'un adjectif démonstratif ?

Un adjectif démonstratif accompagne un nom pour montrer ou désigner une personne, un objet ou une chose.

Exemples :
  • Ce livre est intéressant.
  • Cette maison est grande.
  • Ces étudiants apprennent le français.

Les formes

Forme Utilisation Exemple
Ce Masculin singulier Ce téléphone
Cet Masculin singulier devant une voyelle ou un h muet Cet ordinateur / Cet homme
Cette Féminin singulier Cette voiture
Ces Masculin ou féminin pluriel Ces livres / Ces maisons

🧠 Astuce simple

  • Un objet masculin : ce livre
  • Un objet masculin avec voyelle : cet ordinateur
  • Un objet féminin : cette table
  • Plusieurs objets : ces tables

Singulier et pluriel

Singulier Pluriel
Ce document Ces documents
Cette photo Ces photos
Cet appartement Ces appartements

Possessif ou démonstratif ?

Possession Montrer
C'est mon livre. C'est ce livre.
Cette voiture est ma voiture. Cette voiture est rouge.

⚠ Erreurs fréquentes

❌ Incorrect ✅ Correct
Ce voiture Cette voiture
Cette livre Ce livre
Ce homme Cet homme
Ces voiture Ces voitures

💬 Dialogue

Client : Combien coûte cette chemise ?

Vendeur : Cette chemise coûte 30 euros.

Client : Et ces chaussures ?

Vendeur : Ces chaussures coûtent 50 euros.

✍ Exercices

Complétez avec ce, cet, cette ou ces.

  1. _____ livre est à moi.
  2. _____ maison est très ancienne.
  3. _____ enfants jouent dans le parc.
  4. _____ ordinateur fonctionne bien.
  5. _____ voiture est nouvelle.

✅ À retenir

  • Ce = masculin singulier.
  • Cet = masculin devant une voyelle ou un h muet.
  • Cette = féminin singulier.
  • Ces = pluriel masculin ou féminin.
  • L'adjectif démonstratif s'accorde avec le nom.
