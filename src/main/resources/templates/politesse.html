🤝 La politesse

Apprendre les codes et les expressions de courtoisie en France.

1. Qu'est-ce que la politesse ?

La politesse est un ensemble de règles de comportement qui permettent de vivre en harmonie avec les autres. En France, les salutations et le vouvoiement sont très importants.

  • 👋 Dire bonjour
  • 🙏 Dire s'il vous plaît / merci
  • 🤝 Vouvoyer les inconnus

2. Les expressions essentielles

Expression Usage Traduction
Bonjour Le matin ou l'après-midi. Hello / Good morning
S'il vous plaît Pour demander quelque chose. Please
Merci Pour remercier. Thank you
Pardon / Excusez-moi Si on fait une erreur ou pour passer. Excuse me / Sorry

3. Exemples avec des phrases

👋 Bonjour, comment allez-vous ?
→ Hello, how are you?
🙏 Un café, s'il vous plaît.
→ A coffee, please.
😊 Merci beaucoup pour votre aide.
→ Thank you very much for your help.

4. Le vocabulaire de la courtoisie

  • 🤵 Monsieur
  • 👩 Madame
  • 🎓 le vouvoiement
  • ✨ courtois
  • 💬 saluer
  • 🚪 Pardon

5. Petit exercice

Choisissez la bonne expression.

  1. Quand je demande un service : "__________".
  2. Le matin en arrivant : "__________".
  3. Si je bouscule quelqu'un dans la rue : "__________".
Voir les réponses
  1. S'il vous plaît
  2. Bonjour
  3. Pardon / Excusez-moi

Résumé

  • 🤝 Politesse = Respect et savoir-vivre
  • ✨ Mots magiques : Bonjour, Merci, S'il vous plaît
  • 🤵 Le vouvoiement est la marque de respect de base.
