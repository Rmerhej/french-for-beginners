Les verbes en français

Les verbes permettent d'exprimer une action, un état ou un changement. En français, ils sont classés en trois groupes. Chaque groupe possède ses propres règles de conjugaison.

Le premier groupe

Les verbes du premier groupe se terminent par -ER (sauf aller). Ce sont les verbes les plus nombreux et les plus réguliers.

Exemple : parler

Pronom Conjugaison
Jeparle
Tuparles
Il / Elleparle
Nousparlons
Vousparlez
Ils / Ellesparlent

Exemple : Je parle français.

Le deuxième groupe

Les verbes du deuxième groupe se terminent par -IR et font -issons avec nous. Ils sont réguliers.

Exemple : finir

Pronom Conjugaison
Jefinis
Tufinis
Il / Ellefinit
Nousfinissons
Vousfinissez
Ils / Ellesfinissent

Exemple : Nous finissons le travail à 17 heures.

Le troisième groupe

Le troisième groupe rassemble tous les autres verbes. Ils sont souvent irréguliers. Leur conjugaison doit être apprise progressivement.

Exemple : prendre

Pronom Conjugaison
Jeprends
Tuprends
Il / Elleprend
Nousprenons
Vousprenez
Ils / Ellesprennent

Exemple : Ils prennent le train chaque matin.

Le verbe « aller »

Le verbe aller est particulier. Il se termine par -ER mais il appartient au troisième groupe.

Pronom Conjugaison
Jevais
Tuvas
Il / Elleva
Nousallons
Vousallez
Ils / Ellesvont

Exemple : Nous allons au marché.

Comment reconnaître le groupe d'un verbe ?

  • Les verbes en -ER → premier groupe (sauf aller).
  • Les verbes en -IR qui font nous -issons → deuxième groupe.
  • Tous les autres → troisième groupe.

Conseils pour apprendre

  • Apprenez toujours un verbe avec un exemple.
  • Commencez par le présent de l'indicatif.
  • Répétez les conjugaisons à voix haute.
  • Écrivez une ou deux phrases avec chaque nouveau verbe.
  • Pratiquez un peu chaque jour.

Résumé

Groupe Terminaison Exemple Régularité

2e groupe -IR (-issons) finir Régulier
